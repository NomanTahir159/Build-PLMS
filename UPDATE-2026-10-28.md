# PLMS app package — 28 October 2026

The package is ready to replace the repository contents. Extract `PLMS-Build/`
and upload its contents, including `.github`, to the repository root. Run
**Actions → Build Medicsoft PLMS** to produce the Windows setup EXE.
This ZIP contains source code, not a compiled installer.

## Included application changes

- Lab Identity report header/footer cards, saved signatories and description.
- Conditional report signatory typography and the confirmed multipage logo-line fix.
- Editable trainee letter title, rich text, indentation and independent signatories.
- Letter formatting toolbar: bold, italic, underline, Tab/Shift+Tab first-line indent.
- Separate designation/affiliation, optional affiliation when named, and three
  centered signatories per row with conditional 12 pt / 9 pt typography.
- Saved signatory spacing; PLMS fields, modal header, close controls and tooltips.
- Letter margins of 2 cm; report margins of 1 cm; Duty Roster remains 1.2 cm.
- Lab Identity links for letter header/body/affiliation and Duty Roster.
- Consistent numeric-chevron hover styling across the application.
- Gender / Clinical Condition heading and male-first grouped reference bands.
- AMH Template Preview groups the actual seven configured reference rules before
  pagination: Male first, then Female and its five age bands, preserving ranges.

## Windows integration retained

- `medicsoft-plms.exe` and Medicsoft PLMS branded installer/uninstaller.
- Program: `C:\Program Files\Medicsoft\PLMS\`.
- Data: `C:\ProgramData\Medicsoft\PLMS\`; LIS remains separate.
- Native login, database, backups, audit history, export and printing integration.
- All frontend native actions have matching handlers; `audit_clear` is retained.
- Office/Word integration, Report Designer and Data Folder button remain removed.
- Letter settings now honor `trainees.view` and `trainees.edit` in the native
  database, matching the editor; that grant cannot modify Lab Identity or other
  settings. Rich letter content and gap bounds are validated on native save.
